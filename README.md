# Reversent Business Site v1.0

Plain-language public/company website for Reversent. Designed for non-specialists, business-development conversations, and meetings such as NAV.

## Purpose

Explain the problem, Aegis, the evaluation model, and what already exists without requiring AI-safety or decision-theory background.

## Deploy on GitHub Pages

Upload all files in this folder to the root of a public repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## Research site

The deeper research layer is linked from the site at the current Reversent Research GitHub Pages address.
